# Form & Function website

Complete static website: HTML, CSS, JavaScript, and bundled fonts.

## Run locally

Extract this ZIP, open a terminal in this folder, and run:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000 in your browser. Use a local server because this website uses JavaScript modules. No npm installation or build step is required.

## Hosting

Live site: https://ralphjenrey.github.io/kinetic-ui-sample1/

GitHub Pages serves this repository directly from the root of the `main` branch. Push updates to `main` to publish them. No build step is required. Keep index.html at the root and preserve the fonts directory.

The contact form is a browser-only demo and does not send messages. Project and testimonial content is illustrative.
